## 📌 About This Repository

Welcome to my **Front-End Development Repository**!

This repository is a growing collection of front-end projects, mini applications, UI components, design experiments and practical exercises developed while learning and exploring web development.

It serves as a practical record of my journey in building websites, understanding user interfaces, implementing interactive features and strengthening my development skills through hands-on projects.

Rather than focusing on tutorials alone, this repository emphasises learning by building, experimenting with ideas and improving through implementation.

## 💻 Getting Started

You can explore and run the projects locally.

### 1. Clone the Repository

```bash
git clone https://github.com/palaksharma032/Front-End.git
```

### 2. Navigate to the Repository

```bash
cd Front-End
```

### 3. Open the Project

Open the repository in Visual Studio Code.

### 4. Run a Project

Navigate to the desired project folder and open its HTML file in your browser.

For the main Wanderly website, open the root-level `index.html`.

No build tools or package installations are required for the basic static projects.
